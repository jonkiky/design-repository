## 两种数据模式

**示例预览（默认）：** 包含 4 个虚构案件与 6 份虚构裁判文书。案件编辑、文本材料、筛选、移出与恢复类案、时间线编辑、研究追问、文书版本、复核与下载均可交互。示例数据独立保存在浏览器中，不会写入原服务。研究、生成与配置试运行均使用页面明确标识的预设内容；检索采用本地文本匹配。TXT / Markdown 可本地读取；PDF / DOCX 解析与真实模型能力需要原服务。上传原文件的内存副本只在本次页面会话中可下载，刷新后仍保留元信息与已提取文本。

**连接原有本地服务：** 先按原项目说明启动 `chatbot-system-poc-1106/start.sh`，再运行本目录 `serve.py`。在右上角「示例预览」说明中点击「连接原有本地服务」，使用现有账号登录。也可打开 `http://127.0.0.1:8878/?data=live`。代理默认连接 `127.0.0.1:8765`，保留原有会话、CSRF、来源校验、权限和业务 API。切换数据模式会刷新页面，请先保存编辑内容；连接后操作会保存到原服务。

服务端口可指定：`python3 serve.py --port 8878 --backend-port 8765`。预览服务仅监听本机回环地址。

## 文件与维护

- `index.html`：统一入口。
- `harvey.html`、`harvey-blue.html`、`harvey-red.html`、`harvey-bright-blue.html`、`ao-shearman.html`、`cooley.html`：六个方案入口；`harvey-black-white.html` 是黑白方案的明确命名入口。
- `assets/`：已构建的共享 JavaScript 与 CSS。分享预览时须一起复制。
- `src/themes.css`：三套视觉规则与响应式布局。
- `src/harvey.css`：四种 Harvey 方案共享的排版、导航、灰阶状态与响应式细化。
- `src/harvey-accents.css`：彩色版本共享的强调色、背景与平板/手机风格选择器。
- `src/harvey-bright-blue.css`：截图取色与浅灰导航的蓝灰方案。
- `src/harvey-type.css`：四种 Harvey 方案的字号与阅读体验调整。
- `src/DesignControls.tsx`：主题切换与数据模式入口。
- `src/WorkspaceDashboard.tsx`：新工作台。
- `src/demo.ts`：独立的示例数据适配器；真实模式使用原 API。
- 其余 `src/` 业务组件：从现有应用保留，统一应用新设计。
- `previews/`：实测截图；`verification.json`：初版检查范围；`verification-monochrome.json`：黑白版检查；`verification-accents.json`：蓝、红版本及放大字号检查；`verification-bright-blue.json`：蓝灰方案检查。

修改源码后，在本目录执行 `npm run build`。构建复用相邻原项目已安装的 React、esbuild 等依赖，不复制整个依赖目录。HTML 中的 CSS / JavaScript 地址带内容版本号，防止浏览器继续展示旧设计。

```sh
npm run build
npm test
../chatbot-system-poc-1106/frontend/node_modules/.bin/tsc -p tsconfig.json
python3 scripts/check-live.py
```

真实模型生成、语义检索、生产材料解析和全部真实任务生命周期未在本次设计验收中重新运行；这些能力继续由原应用服务提供。
